## Engineering principles

- Separate presentation, business logic, and data access through explicit
  boundaries.
- Keep secrets outside source control and document every required configuration
  value.
- Make changes verifiable through automated tests, reproducible builds, and
  continuous integration.
- Evaluate models against a baseline, separate training from evaluation, and
  explain precision, recall and false-alert costs.
- Document architecture, trade-offs, setup instructions, security boundaries,
  and known limitations.
- Treat accessibility, privacy, and maintainability as engineering requirements.
